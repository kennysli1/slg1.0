# 外交模块

## 范围

当前只实现玩家之间的三态关系：`allied`（盟军）、`neutral`（中立，默认）和 `hostile`（敌对）。关系按玩家对称保存，未显式保存的玩家对按中立处理。

## 行军门控

- 自己控制的村庄：转移。
- 盟军村庄：增援。
- 中立村庄：增援，或掠夺/攻城并宣战；确认宣战后关系立即变为敌对。
- 敌对村庄：掠夺或攻城。
- 关系判断和宣战由服务端 `diplomacy` owner 权威执行，客户端只展示 `movement.GetMarchOptions` 返回的模式。

## 协议

`diplomacy.GetRelation` 查询关系；`diplomacy.DeclareWar` 由行军模块内部调用并写入敌对关系。`movement.GetMarchOptions` 返回目标可用模式，`movement.PreviewMarch` 返回预计时长、可派兵快照、行军点和集结点等级。

外交谈判、条约有效期、外交 UI 和关系历史不在当前范围内。
