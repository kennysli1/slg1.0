# 外交模块

## 范围

当前只实现玩家之间的三态关系：`allied`（盟军）、`neutral`（中立，默认）和 `hostile`（敌对）。关系按玩家对称保存，未显式保存的玩家对按中立处理。

地图不把外交关系写入地块或探索快照；`vision.FilterArea` 每次响应时查询 Diplomacy 的当前关系，为其他玩家村庄附加 `relation`。客户端分别使用钢蓝、翡绿和绯红边框显示中立、盟军和敌对村庄，关系变化后下一次地图刷新即更新。

## 行军门控

- 自己控制的村庄：转移。
- 盟军村庄：增援。
- 中立村庄：增援，或掠夺/攻城并宣战；确认宣战后关系立即变为敌对。
- 敌对村庄：掠夺或攻城。
- 关系判断和宣战由服务端 `diplomacy` owner 权威执行，客户端只展示 `movement.GetMarchOptions` 返回的模式。

## 掠夺与攻城

- `raid` 是掠夺战：战后仅在进攻方仍有幸存者且获胜时，按幸存进攻战力从城外最高等级建筑逐级拆除；守方可在军队页设置是否派出哪些兵力防守掠夺，掠夺战不启用守方城墙、宝物和科技加成。
- `siege` 是攻城战：守方使用全部驻军以及城墙、宝物、科技加成；战后先按总幸存战力破坏城外建筑，再按攻城武器战力破坏城内建筑。仓库/粮仓存量只在攻城战进入掠夺池。
- 建筑每被拆一级，掠夺收益等于该建筑从上一级升级到当前等级的资源成本；同等级建筑采用稳定伪随机选择。所有阈值、仓储掠夺比例由 `game_constants.csv`（GM 全局常量）调整。
- `combat.BattleEnded` 战报载荷包含 `battleLabel`、`buildingDamage`、`buildingLoot`、`storedLoot` 与双方战损；资源受幸存部队负重限制。

## 协议

`diplomacy.GetRelation` 查询关系；`diplomacy.DeclareWar` 由行军模块内部调用并写入敌对关系。`movement.GetMarchOptions` 返回目标可用模式，`movement.PreviewMarch` 返回预计时长、可派兵快照、行军点和集结点等级。

外交谈判、条约有效期、外交 UI 和关系历史不在当前范围内。
