# 美术生成规范（生成就绪 · 可直接投喂图像模型）

> 视觉基调：**深色石质战争议事厅** —— 厚涂写实、戏剧性打光、鎏金点缀。
> 参照现代手游 SLG（万国觉醒 / 寒霜启示录）的质感层次，**不要网页插画的扁平感**。
> 资产清单的唯一事实源是 **`tools/art_manifest.json`**（138 条，含每张图的 subject 提示词）；
> 名称与 `config/*.csv` 的 `icon` 列对齐，前端只认基名。

---

## 一、核心约定：洋红幕布（解决透明底问题）

图像模型**不能直出 alpha 通道**。所以：

1. 出图时要求主体**孤立在纯平洋红 `#FF00FF` 背景**上（不要渐变、不要晕影、不要投影到背景）。
2. 用 `tools/art_pipeline.py` 抠像：按 `key = min(R,B) − G` 判定背景、羽化边缘、去洋红溢色，
   再裁到主体外接框、补成正方形、降采样。
3. 洋红在中世纪暖色调里几乎不出现，所以红披风、金饰、绿林都不会被误抠。

> 为什么不用绿幕：绿幕会和苔绿、林地、条顿的蓝绿布料冲突。

## 二、流水线（三步）

```bash
# 1) 出图：按 tools/art_manifest.json 的 subject + 下面的风格块喂图像模型
#    文件名必须是 <base>.png（如 bld_barracks.png），全部丢进同一个目录

# 2) 抠像 + 降采样 + 压缩 → 落 packages/client/public/art/
python tools/art_pipeline.py --manifest tools/art_manifest.json --srcdir <出图目录>

# 单张重做：
python tools/art_pipeline.py --src <in.png> --out bld_barracks --mode icon --size 512

# 3) 构建（Vite 把 public/ 拷进 dist/）
npm run build -w @slg/client
```

`--mode` 三档：

| mode | 处理 | 用于 |
|------|------|------|
| `icon` | 抠洋红 → 透明底 + 裁切留边 + 正方形 | 资源/建筑/兵种/宝物/野怪/UI 构件 |
| `tile` | 不抠像，中心裁正方形 | `map_tile_*`、`ui_bg_*` 可平铺材质 |
| `panel` | 不抠像、不裁切，等比缩放 | `bg_login`、`scene_village_ground*` 大场景 |

输出尺寸（`art_manifest.json` 的 `size` 字段）：小图标 256、兵种/野怪 320、建筑/地块 512、大场景 1024。

## 三、风格块（放在每条 subject 前面）

### 3.1 物件 / 建筑 / 资源（`mode: icon`）

```
High-end mobile strategy game asset icon. Hand-painted semi-realistic illustration
with a sculpted, rendered 3D-like finish and rich painterly brushwork; crisp readable
silhouette. Dramatic cinematic lighting: warm key light from the upper left, cool
blue-grey shadow fill, subtle golden rim light along the edges. Deep saturated palette:
aged oak brown, weathered granite grey, dark iron blue-black, mossy green, ember orange,
antique gold accents, deep crimson heraldry. High contrast, polished AAA game icon
quality, gentle ambient occlusion. Single centered subject with generous even padding.
Subject fully isolated on a completely flat solid pure magenta background (hex #FF00FF)
— absolutely no gradient, no vignette, no cast shadow on the background, no ground plane
beneath the subject. NEGATIVE: no text, no letters, no numbers, no watermark, no
signature, no border, no frame, no photorealism, no modern objects, no busy background.
```

### 3.2 兵种角色（`category: unit / merc`）

同上，但把第二句换成：
`Full body, three-quarter front view, standing on nothing.`
并追加 `no extra characters`。**一张图只能有一个角色**（连人带马/带器械算一个）。

### 3.3 UI 构件（`category: ui`）

同 3.1，但材质换成 `sculpted, rendered metal finish`，调色板换成
`antique gold and polished brass with deep crimson cloth accents, dark iron, weathered granite grey`，
并要求 **flat-on 正视、左右对称**。`ui_lvl_badge` / `ui_btn_plate` 的中心必须**留空**（文字由程序绘制）。

### 3.4 地块材质（`mode: tile`）

```
Seamless top-down terrain texture for a strategy game map. Hand-painted semi-realistic
style with rich painterly detail and clear material read. Even ambient daylight, no
strong directional shadows, no vignette, no darkened corners, uniform brightness across
the whole frame. Fully opaque, edge-to-edge full-bleed square filling the entire frame,
tileable with no visible seam. NEGATIVE: no text, no watermark, no border, no frame,
no vignette, no isolated single object, no characters, no photorealism.
```

地块会被裁成六边形并铺满 41×41 的世界，所以**不要有强焦点或明显方向光**，否则会暴露网格。
例外：`map_tile_village` / `map_tile_oasis` / `map_tile_ruins` 本身就是有主体的地块。

### 3.5 大场景（`mode: panel`）

```
Wide cinematic key art for a medieval-fantasy strategy game. Hand-painted semi-realistic
illustration, rich painterly brushwork, dramatic atmospheric lighting with aerial depth
haze, deep saturated palette of weathered stone grey, aged oak brown, mossy green,
antique gold and deep crimson. Fully opaque full-bleed composition filling the entire
frame. NEGATIVE: no text, no letters, no numbers, no watermark, no signature, no UI
elements, no frame, no border, no photorealism, no modern objects.
```

**`scene_village_ground` 是最关键的一张**：村庄主界面的底图，程序会把建筑插画按固定坐标叠在上面。
硬要求：3/4 俯视的**空**村庄地基 —— 建筑垫台上**一栋房子都不能有**，装饰（树林/农田/木栅栏）只放外圈，
全图打光均匀，不要重阴影或压暗的角落（会和叠上去的建筑打架）。

## 四、参考色板

石 `#8c8577` / `#5a5f66`，暗石面板 `#1a2029`，铁 `#39434f`，
金 `#d8b168` / 高光 `#f6e0aa` / 暗金 `#8d6f37`，
绯红 `#a63530`，炭橙 `#e08a3c`，苔绿 `#5f9c62`，钢蓝 `#6f8ba8`，羊皮纸字 `#ece3d2`。
与 `packages/client/src/styles/tokens.css` 同源，改主题先改 tokens 再对齐美术。

## 五、部族视觉识别（兵种必须一眼分清）

| 部族 | 关键词 |
|------|--------|
| 罗马 | 抛光钢质板甲、盔冠、方/鸢盾、绯红配金纹章、几何化的秩序感 |
| 高卢 | 绿与青铜、皮甲锁环、圆盾涡卷绳结纹、连帽斗篷、鹿角羽饰、轻捷剪影 |
| 条顿 | 毛皮与发黑重铁、有角/带翼头盔、长须斧与巨棒、蓝灰与铁锈红、厚重剪影 |
| 雇佣兵 | 混搭捡来的杂色甲片、土黄未染布、腰间钱袋、**完全没有统一纹章** |

## 六、成套一致性检查（出图后自查）

- [ ] 同类别相机角度一致（15 建筑都 3/4 俯视、40 兵种都 3/4 正面同机位）
- [ ] 同类别占画比一致（不忽大忽小；骑兵/器械按**画面高度**对齐步兵）
- [ ] 洋红底纯平无渐变；抠像后放到深底和亮底上都无紫边
- [ ] 无文字/数字/水印/边框
- [ ] 缩到实际显示尺寸（资源 26px / 兵种 68px / 建筑 96px）仍一眼可辨
- [ ] `scene_village_ground` 的垫台确实是空的
- [ ] 文件名与 `art_manifest.json` 的 `base` 完全一致
