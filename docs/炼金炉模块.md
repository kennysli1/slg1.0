# 炼金炉模块

炼金炉是城内建筑 `alchemy`，建成后每次消耗三件相同品质的已存宝物，经过 `game_constants.csv` 的 `alchemy_refine_sec` 秒炼化，产出高一级品质的一件随机宝物。

## 数据与边界

- `alchemy.ts` 是 `alchemy` 集合的唯一 owner，保存三个输入槽、炼化完成时间和待收获结果。
- 宝物库存仍由 `treasures.ts` 拥有；炼金炉通过 `treasure.RemoveForAlchemy` 消耗宝物，通过 `treasure.Grant` 收获，不能直读或直写宝物集合。
- 目标品质按 `common → rare → epic → legendary` 递进；目标品质没有 `dropRate > 0` 宝物时拒绝开始炼化。
- 目标宝物池只包含目标品质且 `dropRate > 0` 的目录项，按 `dropRate` 加权随机；掉率为 0 的任务/特殊宝物不会被炼出。
- 输入槽显示城镇中心、宝库主栏和备用栏的所有宝物副本。第一槽可选全部；第二、第三槽由服务端校验与第一件品质一致。
- 炼化完成后输入清空、结果留在炉内；只有点击收获才调用宝物存入优先级（宝库主栏→城镇中心→备用栏）。无空位时保留结果并返回 `treasure_slots_full`，玩家处理库存后可再次收获。

## 生命周期与动作

`alchemy.Get` 返回建筑等级、输入/结果卡片、可选宝物来源位置、炼化进度与完成时间；`alchemy.Select` 选择输入并原子消耗宝物；`alchemy.Start` 登记 Scheduler 任务；完成任务后 `alchemy.Updated` 推送；`alchemy.Claim` 收获结果。刷档、放弃村庄和删号会取消 `alchemy:<villageId>` 调度任务并删除集合记录。

## 配置

- `config/buildings.csv`：建筑目录与 `inner` 区归属。
- `config/building_levels.csv`：1–5 级成本、耗时。
- `config/game_constants.csv`：`alchemy_refine_sec` 炼化时长。
- `config/treasures.csv`：品质、图标、名称与 `dropRate`，是炼化结果概率事实源。
