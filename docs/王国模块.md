# 王国模块

## 世界结构

王都是 `kingdom-capital` PvE，固定在世界中心并占用 6 个连续六边形格，形状为上窄下宽的倒三角（三行 `1+2+3`）；东北、东南、西南、西北四个封地是 `kingdom-fief-*` PvE，位于四个象限中心并各占用 3 个连续格，形状为上窄下宽的倒三角（两行 `1+2`）。每个地标只有中心格作为唯一战斗/行军目标，其余格与中心共享同一 `refId`，用于地图辨识和占地阻挡；偏移比例来自 `kingdom_fief_offset_ratio`。客户端将同一地标的占地合并绘制为一块无内部格线的地图轮廓，悬停时整块高亮，王都/封地图标按整体轮廓居中并限制在轮廓边界内。五个地标与随机城邦都使用 `pve_targets.csv` 的 `kingdomProfile` 接入统一王国 PvE 生成器：城邦按一级/二级/三级，四个封地按统一高于三级的 `fief` 档，王都按更高的 `capital` 档，随机种族兵种、城内外建筑、资源、掠夺防守兵力，并共享兵力/资源恢复与受击重置规则。新世界生成时优先保留这些格；旧世界启动时会按生成规则版本重建缺少档位字段的王国 PvE，不覆盖玩家或其它目标。

玩家首次进入系统时按出生村坐标固定归属一个封地，之后移动村庄不会改变效忠关系。`kingdom.ts` 是 `kingdom` 集合的唯一 owner；老账号没有记录时惰性建立，属于向后兼容扩展。

## 循环王国任务

王国任务是玩家全局任务，在任务页“全局任务 → 王国任务”显示。任务由 Scheduler 在可配置随机间隔后发放，有独立期限；执行中超时只记失败且无惩罚。目标完成后进入 `ready`，冻结期限并等待玩家领取奖励；只有领取后才重新安排下一轮循环。

王国 PvE 战斗会按守军兵种 `popCost` 累计实际消灭人口：每满 `kingdom_pve_killed_population_per_reputation` 人扣 1 点声望，余数跨战斗保留。每累计 `kingdom_pve_retaliation_chunk` 点该类扣分检查一次当前声望；达到掠夺或攻城阈值时，由玩家出生象限对应封地派出随机雇佣军。报复军不扣封地原守军、不占玩家人口；战后幸存者携带战利品返回封地并解散，战利品通过 `pve.DepositLoot` 回存封地库存。

当前目标池：

- 上贡随机一种资源；当前村庄一次上交完整需求。
- 清理出生象限内一座地图既有的普通 PvE；不生成任务专属营地。
- 攻打出生象限内声望严格低于配置门槛的指定玩家。
- 累计消灭上述指定玩家的一定数量兵力。

完成目标只把任务改成 `ready`。玩家必须手动领取，`reputation.Adjust` 才会发放声望；领取后再安排下一轮任务。任务权重、首次等待、循环间隔、期限、目标量、负声望门槛与四类奖励全部在 `game_constants.csv` 的 `kingdom_*` 行，由配置中心平衡面板写回 CSV 并热重载。

## 议会厅

`council` 是 1–5 级城内建筑，每村最多 1 座且要求主基地至少 2 级；建筑本身还需通过 M11 交付奖励解锁（旧存档中已存在的议会厅保持兼容）。`kingdom_services.csv` 定义服务类型、议会厅等级门槛、声望价格、兵种与数量、资源、宝物和执行延迟：

- `supplies`：资源和金币直接发到当前村。
- `reinforcement`：配置兵种直接加入当前村驻军。
- `treasure`：按宝物统一存入规则发放；满栏进入对应村庄报告待处理。
- `attack`：选择当前地图可见或已探索的非己方目标；王国军延迟后直接加入正常 PvE/PvP 战斗。
- `escort`：从当前村出发或前往当前村的送货商队中选一支，立即附加隐藏王国护卫。仅保护当前送货段，送达或提前返程时解除；不能重复购买，护卫不加入玩家驻军。默认 `caravan_guard` 为 3 声望、100 军团兵，门槛/价格/数量在配置中心“议会厅王国服务”编辑。

护卫购买先校验目标，再扣声望并复检保护资格；并发购买或目标失效时退回原价，退款不会再触发形象大使的额外声望奖励。

购买通过 `reputation.TrySpend` 原子扣声望，不能透支成负声望。代打出发前目标失效会失败并自动退款。王国代打军标记为 NPC：不占玩家人口、不触发玩家医院回收、不替玩家领取 PvE 宝物；除玩家购买服务外没有任何主动攻击调度。

## 外部动作与事件

- `GetKingdomState`：玩家归属、当前任务、地标、议会厅等级、服务与订单。
- `SubmitKingdomTribute` / `ClaimKingdomTask`：上贡与手动领赏。
- `BuyKingdomService`：购买即时或延迟服务。
- `kingdom.Updated` → `KingdomUpdated`：按 `playerIds` 推送，客户端轻量重拉王国快照。

没有议会厅时，王国任务不发放、不计时且任务页隐藏王国任务菜单；建成并解锁议会厅后立即启用循环任务。联盟大厅（`alliance_hall`）同样要求主基地至少 2 级、每村最多 1 座，由 M11 交付解锁，当前仅作为联盟系统预留建筑。

刷档会清空 `kingdom` 进度；删除账号会取消该玩家任务/订单调度并删除记录。正常部署与旧存档升级不需要 `respawn`。
