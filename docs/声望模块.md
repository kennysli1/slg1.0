# 声望模块

## 职责与数据

`reputation.ts` 是玩家声望的唯一 owner，使用 `reputation` 集合按 `playerId` 持久化。没有记录的玩家惰性初始化为 0，因此老存档和删档后都兼容。正数为正声望、负数为负声望、0 为中立。

## 命令与事件

- `reputation.Get`：按玩家读取声望及派生效果。
- `reputation.GetByVillage`：按当前村庄读取声望，供资源栏和 PvE 掉落查询。
- `reputation.Adjust` / `reputation.AdjustByVillage`：由任务等跨模块行为调整声望。
- `reputation.SetTreasureDelta`：同步主宝物栏被动声望修正。
- `reputation.ProcessPvpBattle`：PvP 战斗结束后按目标声望门槛和消灭的士兵人口结算奖励。
- `reputation.Changed` → `ReputationChanged`：客户端刷新资源栏。

跨模块写入遵循 Command/Event 边界：声望模块只向 `population.SetReputationGrowthMult` 和 `population.SetReputationGoldTaxMult` 推送最终倍率，不直接写人口集合；军队通过 `reputation.GetByVillage` 取得最终攻防倍率；宝物模块只通过 `reputation.SetTreasureDelta` 传入主宝物栏被动修正。

## 当前规则（均可由 GM 调整）

- S4 释放被囚禁的娜塔莉们：`+2`；收纳分支任务失败：`-2`。
- S3 完成幸福村请求并获得「娜塔莉」：任务结算 `-1` 声望；两个娜塔莉宝物本身不再提供被动声望。
- 正声望玩家攻击声望严格小于 `-10` 的玩家：每消灭十点敌方士兵人口获得 `+1` 声望，未满十点的击杀余数会保留。
- 负声望玩家攻击声望严格大于 `10` 的玩家：每消灭十点敌方士兵人口增加 `-1` 声望，未满十点的击杀余数会保留。
- 正声望人口增长倍率：每点 `+0.5%`，最多 `+50%`；负声望人口增长倍率：每点 `-0.5%`，最多 `-50%`。
- 正声望金币税收倍率：每点 `-0.5%`，最多 `-50%`。
- 负声望 PvE 宝物掉落概率倍率：每点 `+1%`，最多 `+50%`；只作用于普通 PvE 营地总体掉落概率门控，任务营地的强制任务宝物不受影响。
- 负声望军队攻防倍率：默认每点负声望攻击 `+0.5%`、防御 `+0.5%`，分别最多 `+50%`；GM 可独立调整每点倍率和上限，作用于出征、守城和掠夺防守的军队快照。

## 客户端与 GM

资源栏最左侧显示当前声望、正/负/中立标签；悬浮提示同时显示人口增长、军队攻防、金币税收和 PvE 宝物掉落效果。配置中心 `/config/balance` 的“声望参数”板块集中编辑所有行为、门槛、击杀奖励和倍率上限，任务图的 `adjust_reputation` 效果负责任务结算声望，保存后通过现有热重载持久化。

本模块为向后兼容新增集合，不要求刷档；`resetWorld` 会清空声望进度，账号删除会清理对应玩家记录。
