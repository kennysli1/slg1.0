# 声望模块

## 职责与数据

`reputation.ts` 是玩家善恶值的唯一 owner，使用 `reputation` 集合按 `playerId` 持久化 `{ value, updatedAt }`。没有记录的玩家惰性初始化为 0，因此老存档和删档后都兼容。正数为善、负数为恶、0 为中立。

## 命令与事件

- `reputation.Get`：按玩家读取声望及派生效果。
- `reputation.GetByVillage`：按当前村庄读取声望，供资源栏和 PvE 掉落查询。
- `reputation.Adjust` / `reputation.AdjustByVillage`：由任务等跨模块行为调整声望。
- `reputation.ProcessPvpAttack`：一次已成功派出的 PvP 攻击按目标善恶门槛结算攻击奖励。
- `reputation.Changed` → `ReputationChanged`：客户端刷新资源栏。

跨模块写入遵循 Command/Event 边界：声望模块只向 `population.SetReputationGrowthMult` 推送最终人口倍率，不直接写人口集合。

## 当前规则（均可由 GM 调整）

- S4 释放被囚禁的娜塔莉们：`+2`；将其收入宝库：`-2`。
- 善值大于 0 的玩家攻击善恶值严格小于 `-10` 的玩家：每次成功派出攻击 `+2` 善值。
- 恶值小于 0 的玩家攻击善恶值严格大于 `10` 的玩家：每次成功派出攻击 `-2`（恶值绝对值增加）。
- 善值人口增长倍率：每点 `+0.5%`，最多 `+50%`；与宝物、科技倍率相乘。
- 恶值 PvE 宝物掉落概率倍率：每点 `+1%`，最多 `+50%`；只作用于普通 PvE 营地总体掉落概率门控，任务营地的强制任务宝物不受影响。

## 客户端与 GM

资源栏最左侧显示当前声望、善/恶/中立标签；悬浮提示同时显示人口增长和 PvE 宝物掉落效果。GM `/gm/balance` 的“善恶 / 声望参数”板块集中编辑所有行为、门槛、奖励和倍率上限，保存后通过现有热重载覆盖持久化。

本模块为向后兼容新增集合，不要求刷档；`resetWorld` 会清空声望进度，账号删除会清理对应玩家记录。
