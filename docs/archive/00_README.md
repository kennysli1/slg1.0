# 世界之王 (KOW) 项目

> 📌 **理解整个项目请先看仓库根的 `PROJECT.md`**（项目入口：是什么/目录/架构/模块/怎么配置扩展修改运行）。本文只记设计推进流程与进度。

> 核心诉求：**先把系统接口/架构跟人商量定死，再开发**，避免 AI 一把梭写死、系统间耦合不清、后续难改。

## 三阶段流程（按此推进）

```
阶段一 · GDD       从零出发，基于"好玩"构建系统清单，逐系统标【保留/修改/新增】
   │
   ▼
阶段二 · 架构      ★重点★ 由 AI 据 GDD 产出：模块职责 + 模块间接口契约（传什么数据/事件）
   │               + 数据归属 + 扩展点。这层决定"以后好不好改"，慢工细做。
   ▼
阶段三 · 代码      架构签字后才动手。
```

**关键原则**：自顶向下锁接口，不自底向上抠玩法细节。玩法细节（如资源几种）等架构成型后再填。

## 已敲定的方针（阶段一基调）

1. 先把**基础循环**做出来、做有趣；玩家定位/优化/社交/赛季后置。
2. **PvE 与 PvP 共用同一套养成 + 战斗数值**：一支军队一套数值；PvE=稳定发育，PvP=掠夺加速，战利品回流同一经济。
3. 先**单人**，不做社交/联盟。
4. 先不承诺**赛季制**，先跑通一个局内玩法。

## 下一步
