# 美术资源清单

> **资产的唯一事实源是 [`tools/art_manifest.json`](../tools/art_manifest.json)**（144 条）。
> 每条含 `base`（文件基名）/ `zh`（中文名）/ `category` / `mode` / `size` / `subject`（出图提示词）。
> 本文只讲**约定**与**清单概览**；具体提示词与风格块见 [`美术生成规范.md`](./美术生成规范.md)。

## 一、命名与引用约定

- 文件名 = `<前缀>_<键名>`，全小写下划线，**不带扩展名地写进配置**。
- 正式格式是 **WebP**（`packages/client/public/art/<base>.webp`）。
  唯一例外：`ui_logo` 另存一份 `.png`，供 PWA manifest 与 apple-touch-icon 使用。
- `config/*.csv` 的 `icon` 列填的就是 `base`；服务端 `GetGameConfig` 下发，前端拼路径：
  `artPath(base) → /art/<base>.webp`（见 `packages/client/src/ui/Icon.tsx`）。
- **缺图不会破图**：`<Icon>` 加载失败自动退化为文字徽标，所以可以先写代码后补图。
- 加新内容（兵种/建筑/宝物）时：CSV 填 `icon` → 在 `art_manifest.json` 追加一条 → 出图 → 跑流水线。**不需要改前端代码。**

## 三、两张关键图的额外约束

- **`scene_village_ground`（村庄底图）**：村庄主界面的地基。程序把建筑插画按
  `features/village/scene-layout.ts` 的归一化坐标叠在垫台上，所以底图的垫台必须是空的、
  打光均匀。换这张图**必须同步重校** `scene-layout.ts` 的坐标（可用 `python tools/scene_pads.py` 量一版初值再目视微调）。
- **`map_tile_*`（地块）**：会被裁成六边形铺满 41×41 世界，不能有强焦点或方向光，否则暴露网格。
